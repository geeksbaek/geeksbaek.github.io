오늘의 흐름

  • 토스커뮤니티 대규모 채용(~10/11)의 실질 마지막 지원일이 오늘이다. 10/9 한글날과 주말을 빼면 남은 영업일이 없다. iOS는 토스 본체와 토스플레이스 두 갈래이고 계열사 중복 지원이 불가해 지원처를 고르는 데도 시간이 든다.
  • 여드레 연속 같은 11건이다 — 신규도, 내려간 공고도 없다. 9/30 네이버웹툰 공고가 마감돼 12건에서 11건이 된 뒤 목록이 그대로 멈춰 있다.
  • 넥슨 조회는 아흐레 연속 정상이다(127건 스캔). 9월 말 Cloudflare 403 으로 막혔던 job-posts API 가 안정화됐고, iOS 공고는 확인된 0건이다.
  • 퓨리오사AI(furiosa-ai) Ashby 보드는 아흐레 연속 조회 실패다. 오늘 보완 검색으로 자사 채용 페이지(furiosa.ai/careers)의 공고 48건을 전수 확인했고 iOS·Swift 자리는 없었다 — 다만 보드 API 자체는 못 읽었으므로 0건이 아니라 미확인으로 남긴다.
  • 신입·병역특례로 들어갈 길은 넛지헬스케어(캐시워크) 3건뿐이다. 나머지 8건은 전부 경력 정규직이고, 3년+·7년+ 로 연차를 못 박은 자리가 섞여 있다.
