오늘의 흐름

  • 목록은 어제와 완전히 같은 12건이다. 신규도 내려간 공고도 없다. 네이버웹툰·토스커뮤니티 대규모 채용이 붙은 뒤 사흘째 같은 구성이 유지되고 있다.
  • 네이버웹툰 접수가 오늘 밤(9/30 23:59) 끝난다. 지원 의사가 있다면 오늘이 마지막이다. iOS 6년 이상 + Swift 숙련에 Combine·Swift Concurrency(async/await) 실무 경험을 자격요건으로 못 박은 자리다.
  • NHN ACE 공고가 NHN 채용 목록에서 사라졌지만 공고 자체는 살아 있다. 공고의 직무분류(jobSeries)가 빈 값으로 바뀌어 iOS·Android 분류 목록과 전체 목록 어디에도 뜨지 않는데, 상세 API 는 postingYn=Y / finishYn=N 으로 게시중이다. 즉 직접 링크로만 닿는 상태다. 오늘 크롤러에 전체 목록 키워드 스캔과 직접 상세 확인 경로를 추가해 다시 잡아냈다.
  • 넥슨 조회가 사흘 만에 복구됐다. 이틀 연속 Cloudflare 403 이던 job-posts API 가 오늘은 정상 응답해 127건을 조회했다 — 그중 iOS 공고는 0건이다. 이제 '미확인'이 아니라 확인된 0건이다. 남은 조회 실패는 Ashby 퓨리오사AI 보드 한 곳뿐이다.
  • 총 스캔량은 어제 4,552건에서 4,667건으로 늘었다. 대기업 트랙은 여전히 상단 경력 구간(쿠팡 Staff, 카카오스타일 7년+, 네이버웹툰 6년+)에 몰려 있고, 신입이 지원할 수 있는 자리는 캐시워크 채용전환형 인턴 하나뿐이다.
